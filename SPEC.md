# Portfolio Website for Sanjay Chunduru

## Objective
Build a modern, responsive, and visually appealing portfolio website for Sanjay Chunduru. Model it after this website: https://amirmxt.com/?ref=deadsimplesites, and include all the pages in the website, including a space to write posts (https://amirmxt.com/blog), a space to display work (https://amirmxt.com/work), and a space to display projects (the website doesn't have a projects page, but make one for me. It should be similar to the work page). Further, the main page for the reference contains a section for "Videos"; replace that with a section for "Projects".

## Pages
- Home
- Work
- Projects
    - Can include GitHub repos, links to other websites, demos, etc.
- Blog
    - Use MDX for the blog posts.
- Contact (doesn't exist in the reference website, but make a simple page to display my email, x account, and linkedin).

## Design
- The website should be responsive and work on all devices.
- The website should be visually appealing and modern.
- The website should be easy to navigate.
- The website should be fast and efficient.
- The website should be accessible to all users.

## Tech Stack
- Use Next.js for the website.
- Use Tailwind CSS for styling.
- Use TypeScript for the website.
- Use shadcn/ui for the website.

## Notes
- The font should be the exact same as the reference website.
- For all sections in the main page, display the first 3 items, scrollable to see all items, or a view all button that takes you to the respective page.
- The website should be optimized for SEO.
